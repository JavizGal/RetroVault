# 🎮 RetroVault

**RetroVault** es un emulador en linea con juegos disponibles para utilizarlos en linea sin necesidad de descargar nada en tu computadora.

> ⚠️ **Nota:** Los juegos de PS1 no estan incluidos en el repositorio ya que github no permite subir mas de 100 mb por archivo.

---

## 🚀 Características

* 🎮 Catálogo de videojuegos retro.
* 📱 Interfaz adaptable a diferentes tamaños de pantalla.
* ⚡ Interfaz dinámica mediante JavaScript.
* 🎨 Diseño personalizado con CSS.
* 💾 Estructura preparada para agregar más plataformas y juegos.
* 📂 Organización de contenido por consola.

---

## 🖥️ Plataformas

Actualmente el proyecto cuenta con contenido organizado para:

* Nintendo Nes
* PlayStation 1

La estructura está preparada para poder incorporar posteriormente otras plataformas.
